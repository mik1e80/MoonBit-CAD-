## 本次重点修复

1. 跨草图同号句柄曾被错误视为有效对象，可能误读、误改或关联错误几何。现通过草图身份标识校验查询、编辑、关系、结果与报告。

moon test --target js

moon run examples/basic
moon run cmd/edit_demo

moon run examples/mirror_holes

## 2026-10-22 失败诊断排序

新增 6 项回归及 1 项可执行公开接口示例，覆盖不同单位残差的误差比排序、并列项、禁用项、容差边界、空 / 欠约束 / 冗余模型、独立数组、实际矛盾和删除恢复、历史快照，以及可解模型因奇异初值停滞的反例。分发包独立消费方另验证带编号空缺的真实诊断。
