# 项目定位与范围

## 一句话定位

MoonBit CAD Sketch 是面向 MoonBit 应用开发者的小型二维参数化草图约束求解库：将点、线、圆及设计关系转换为非线性方程，求解坐标与半径，并提供尺寸编辑后的重新求解和约束诊断。

模块名为 `mik1e80/cad_sketch`。核心库使用纯 MoonBit 实现，仅依赖 MoonBit core，支持 wasm、wasm-gc、JS 和 native。当前源码版本为 `0.1.0`，发布状态以 [README](../README.md#当前版本) 为准。

## 面向谁，解决什么问题

| 目标用户 | 具体需求 | 本项目提供的能力 |
| --- | --- | --- |
| 参数化零件工具开发者 | 改宽度、孔距、对称轴或半径后，按已有设计关系更新关联几何 | 点、线、圆建模；距离、方向、对称、相切等 24 种约束；修改约束后重新求解 |
| 草图编辑器和工程工具开发者 | 在自己的界面中连接几何、参数编辑与诊断 | 稳定的草图内句柄、约束启停、逐约束残差、局部自由度及求解状态 |
| 几何与机构教学工具开发者 | 展示几何关系、参数变化和机构构型 | 可检查的求解结果、命令行示例，以及包含连续曲柄位置的四杆机构测试 |

这些用户需要把设计关系表达为约束。例如，两孔关于一条直线对称且等半径时，可以组合圆心的 `Mirror` 与圆的 `EqualRadius`；移动对称轴后继续求解，无需在应用中另写一套孔位联动公式。

## 核心价值

- **在 MoonBit 应用内完成求解**：核心求解过程不依赖 C/C++ 求解器、FFI 或 JavaScript 数学库。
- **按关系编辑几何**：尺寸、方向、对称和相切关系共同参与求解，支持修改已有约束及临时启停。
- **让结果可检查**：返回每条约束的残差、求解状态和局部自由度；调用者可以将诊断映射回草图对象。

这里的价值来自当前接口与实现，不包含尚未测量的性能优势或对任意草图的收敛保证。变量建模、自动微分、阻尼迭代与 QR 求解详见 [技术路径说明](ARCHITECTURE.md)。

## 典型使用流程与现有证据

1. 创建 `Sketch`，添加点、线、圆，并设置接近目标构型的初始几何。
2. 添加定位和设计关系，保存需要编辑的约束句柄。
3. 调用 `solve()` 检查结果，或使用 `solve_and_apply()` 在全部约束达到容差时更新几何。
4. 使用 `set_constraint()` 修改尺寸，再次求解；使用 `set_constraint_enabled()` 暂停或恢复某条关系。
5. 读取状态和逐约束残差，定位当前未满足的关系；若本次未成功应用，保留上一次成功几何以供继续编辑。

## 当前能力边界

- **几何和关系**：点、线段、圆及 24 种等式约束。点在线上、点线距离、线圆相切和镜像轴按无限延伸直线计算。
- **规模**：最多 256 个标量变量、512 条线、512 条存储约束。点占两个变量，圆半径另占一个变量；禁用约束仍占存储名额。这是输入上限，实际性能需由 Benchmark 测量。
- **编辑行为**：每次求解重新线性化，使用稠密矩阵。当前提供尺寸修改与约束启停，尚无稀疏增量求解、约束删除或拖拽优先级。
- **收敛条件**：局部非线性迭代依赖初值、构型、尺度和容差。未收敛不证明无解；当前未满足关系也不是经过证明的最小冲突集。
- **诊断含义**：`local_dof` 是返回构型下雅可比的一阶数值估计，不能证明全局刚性；欠约束时也不保证结果离初值最近。
- **应用交付**：核心库提供建模、求解和诊断，命令行示例展示典型编辑流程。完整 CAD 编辑器、模型持久化、DXF 导入导出、三维几何、圆弧、样条和不等式约束均在核心库当前范围之外。应用界面、模型存储和文件互转由集成方实现。

本库适用于可以表达为小型二维几何等式系统的应用。若需要完整 CAD 工作流、大型装配、任意初值全局求解或软约束优先级，应先评估相应专用工具。相关项目的范围说明见 [README 的生态对比](../README.md#与相关项目的区别)，引用与来源见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
